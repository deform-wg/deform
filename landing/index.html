01 / THE IDEA

Write the rules.
Get the form.

Keep form structure where your application logic lives. A configuration describes sections, fields and behavior; the <de-form> component takes it from there.

profile.ts
import '@deform-wg/deform';

const form = document.querySelector('de-form');
form.fields = {
  theme: 'light',
  accent: 'sky',
  sections: [{
    name: 'profile',
    submitLabel: 'Save details',
    fields: [
      { name: 'name', type: 'text',
        label: 'Your name', required: true },
      { name: 'account', type: 'select',
        label: 'Account type',
        options: [
          { value: 'personal', label: 'Personal' },
          { value: 'business', label: 'Business' }
        ] },
      { name: 'company', type: 'text',
        label: 'Company name',
        revealOn: ['account', '=', 'business'] }
    ]
  }]
};
One import. One element. Your rules.TS / JS
